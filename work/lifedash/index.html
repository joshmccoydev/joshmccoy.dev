LifeDash

A passive three-column board for the TV next to my desk.

Personal, work and build, and digital. No chatbot, no database, nothing to click. It is a board I can read from across the room.

There is no public demo. A GitHub link used to sit on the homepage, and it does not open for the public, so I took it off.

Built with Next.js 16, React 19, TypeScript, and Tailwind 4.
